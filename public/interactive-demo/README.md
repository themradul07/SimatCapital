# Simat Capital & Shariah Ops — Unified Platform

This is the combined, deduplicated master presentation uniting:
1. **Simat Capital** (Asset Management / Investor Demo)
2. **Simat Shariah Ops** (FundOps & Compliance Platform / Client Demo)

## Features

- **Zero Duplicates**: Complete coverage of all 38 unique slides across both decks, with seamless transitions and no clashing styles, variables, or SVG IDs.
- **Deck Switcher**: Switch dynamically between:
  - **Master Tour (38 Slides)**: The complete unified journey from market problem, asset management philosophy, alpha generation, to the automated back-office and compliance platform.
  - **Simat Capital (21 Slides)**: The dedicated LP / investor presentation for the Flagship Fund.
  - **Simat Shariah Ops (17 Slides)**: The full product demo for institutional clients, fund administrators, and family offices.
- **Full Interactivity**: All interactive calculators, 90-day grace period clock, tax-lot purification ledger, live 20-holding portfolio check, scholar audit log, 5-page audit pack, and fee simulation remain 100% functional.
- **Self-Contained Resources**: Bundled with `support.js`, `vendor/react.js`, and `vendor/react-dom.js`.

## Viewing

Open either `index.html` or `Main.dc.html` in your browser.

If your browser blocks scripts over `file://`, serve the folder with any static HTTP server:
```bash
python -m http.server 8000
# or: npx serve .
```
and visit `http://localhost:8000/index.html`.
